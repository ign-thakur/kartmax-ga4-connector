# KartmaX GA4 Connector

GA4 analytics connector for KartmaX: MCP-backed GMV/Sessions source reports, direct GA4 Events, REST v1 API, JWT auth, Google Sheets export, and an optional JWT ops console at `/ops` (`ENABLE_OPS_CONSOLE=true`).
